\section{Introduction}
This report provides a comprehensive evaluation of Deep Learning (ResNet-18, ResNet-50) and Machine Learning (SVM) models on the MNIST and FashionMNIST datasets. The primary focus is to analyze how architectural depth, hardware acceleration, and various hyperparameters impact classification accuracy and computational throughput (GFLOPs).

In addition to accuracy, this study emphasizes practical DL-Ops considerations such as training time, optimizer behavior, memory management, and CPU vs GPU execution. By training all deep learning models from scratch and performing a systematic hyperparameter sweep, the experiments aim to highlight the trade-offs between model complexity and efficiency, especially when large CNN architectures are applied to low-resolution image datasets.

\section{In-Depth Analytical Discussion}

\subsection{Architectural Efficiency vs. Image Resolution}
One of the most notable outcomes is that \textbf{ResNet-18} consistently outperformed \textbf{ResNet-50} in accuracy across nearly all FashionMNIST configurations. Mathematically, ResNet-50 possesses more than double the GFLOPs (0.166 vs 0.071). However, since the input resolution is very low ($28 \times 28$), the deeper model likely encounters the "overfitting" or "degradation" problem earlier than a shallower network. The ResNet-50 architecture is designed for $224 \times 224$ images; when applied to MNIST, many of its deeper layers may be learning redundant or noise-related features.

\subsection{Influence of Optimizers and Learning Rate}
The \textbf{Adam} optimizer generally yielded higher stability and better final accuracy compared to SGD. This is attributed to Adam's adaptive moment estimation, which adjusts the learning rate for each parameter individually. Conversely, \textbf{SGD} required a higher number of epochs to converge. Reducing the Learning Rate from $0.001$ to $0.0001$ resulted in a significant accuracy drop (e.g., from 88\% to 82\% for ResNet-50 in some runs), indicating that $0.0001$ is too low to navigate the loss landscape effectively within 3-5 epochs.

\subsection{Memory Management and Hardware Acceleration}
The use of \texttt{pin\_memory=True} showed a consistent reduction in epoch time (approx. 5-7\%). This is because pinned memory prevents the operating system from swapping the data to disk, allowing the GPU to use Direct Memory Access (DMA) to pull data from the RAM more efficiently. Combined with \texttt{USE\_AMP} (Automatic Mixed Precision), which uses FP16 for calculations, we achieved a \textbf{12.5x speedup} on the GPU compared to the CPU.

\subsection{CNN vs. Traditional Classifiers (SVM)}
The SVM with an RBF kernel provides a respectable baseline ($\sim$97.92\% on MNIST). However, the training time for SVMs increases cubically with the size of the dataset. Deep Learning models, while having a high initial overhead, scale better to large datasets. Furthermore, the CNN's ability to preserve spatial hierarchies (edges $\rightarrow$ shapes $\rightarrow$ objects) makes it fundamentally superior to the flattened-vector approach of the SVM for image tasks.
